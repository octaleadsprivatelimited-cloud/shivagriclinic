# SEO setup

The public pages are `/`, `/videos`, `/about`, `/contact`, `/team`, `/featured-in`, `/blog`, `/case-studies`, `/privacy-policy`, and `/terms`. Their English fallback titles, descriptions, and keyword phrases live in `src/data/seoPages.json`. The site editor at `/admin/content` can change public page titles and descriptions at runtime. The build also generates route-specific HTML heads from the fallback values so link previews can read titles and descriptions without running JavaScript. The retired `/crop-management` URL redirects to `/videos` and is absent from the sitemap.

The canonical host is `https://www.shivaagriclinic.com`. Its apex currently redirects to `www`. Set `VITE_SITE_URL` to this HTTPS origin for production builds if the host changes. `public/sitemap.xml` lists the ten public static routes, and `public/robots.txt` points to it. The sitemap omits admin and API URLs. The robots file blocks crawling under `/api/`. Production hosting sends `X-Robots-Tag: noindex` for admin pages; robots.txt allows crawlers to reach them so they can read that directive. [Google explains why a robots block can prevent `noindex` from working](https://developers.google.com/search/docs/crawling-indexing/block-indexing).

The favicon files at `/favicon.ico` and `/favicon-shiva-48.png` (plus larger PNG and Apple icons) are cropped from the round logo shown in the site header. `index.html` points to these stable, crawlable URLs. The build adds homepage `Organization` structured data with `/favicon-shiva-512.png` as its logo. After deploying to the canonical host, confirm that `/favicon.ico` returns an image rather than the SPA HTML fallback and that the homepage's icon links point to the new files. Then request a homepage recrawl in Google Search Console if the property is available. Google's favicon and logo display can take days or weeks after a crawl and is not guaranteed.

`src/components/SEO.tsx` updates metadata when users navigate or switch language. It adds Organization and WebSite structured data on the homepage and VideoObject data on watch pages when the YouTube publish date is available. Watch pages and individual blog posts use generic route shells; their item-specific metadata is currently client rendered. A server-rendered response would improve previews in crawlers that do not run JavaScript. Automatically uploaded watch URLs and published blog post URLs are not included in the static sitemap.

The pages include a small, relevant `meta keywords` field because it was requested. [Google ignores this field for indexing and ranking](https://developers.google.com/search/docs/crawling-indexing/special-tags); titles, descriptive page copy, internal links, and crawlable HTML matter more.

The `shivaagriclinic.com` domain property was verified in Shiva's [Google Search Console](https://search.google.com/search-console) using its existing DNS record on 15 November 2026. The canonical `https://www.shivaagriclinic.com/sitemap.xml` was submitted successfully. Inspect the homepage, videos page, and representative watch pages as Google processes the new site. Search Console access and ranking data are outside this repository.
